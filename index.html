Witness: Open-source framework for verifying how your software was built

Witness es una herramienta de código abierto diseñada para registrar el proceso de construcción de programas informáticos, firmar dicho registro y validarlo mediante una política antes de que el software sea distribuido. Creada originalmente por TestifySec, la herramienta fue donada al ecosistema in-toto dentro de la Cloud Native Computing Foundation y actualmente cuenta con el mantenimiento de una comunidad abierta. El funcionamiento de la herramienta consiste en envolver el comando de compilación para generar un archivo JSON con declaraciones firmadas sobre los componentes utilizados, la orden ejecutada y los productos obtenidos.

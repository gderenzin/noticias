El «Patch Tuesday» de octubre de 2026 de Microsoft corrige 1.411 vulnerabilidades, 3 de ellas de día cero

El evento de seguridad Patch Tuesday de Microsoft ha lanzado actualizaciones para solucionar una cifra histórica de vulnerabilidades, la cual incluye un fallo que ha sido explotado activamente y otros dos que se dieron a conocer públicamente sin parche previo. Entre el total de problemas resueltos se encuentran decenas de incidencias catalogadas como críticas, abarcando categorías como ejecución remota de código, elevación de privilegios y suplantación de identidad. Entre las vulnerabilidades de tipo cero días corregidas destaca un problema en el componente Windows Shell que permitía eludir las protecciones de Mark of the Web mediante comandos, además de un fallo en el entorno .NET Framework que posibilitaba la ejecución de aplicaciones no autorizadas al sortear el control de aplicaciones de Windows Defender, y una falla de denegación de servicio relacionada con el manejo de memoria en MessagePack-CSharp.

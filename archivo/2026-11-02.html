DeepSeek open-sources Super-Agent, a coding agent that watches team chats for work

DeepSeek ha lanzado como código abierto un prototipo de investigación denominado dsh-superagent, el cual consiste en un agente de programación capaz de realizar tareas directamente en un repositorio de GitHub. Este agente comienza a trabajar bajo dos circunstancias específicas: cuando un usuario autorizado se lo solicita o cuando una regla establecida por el equipo contempla dicha acción. Asimismo, es posible habilitar un chat o un ámbito de GitHub para que cualquier persona dentro de este pueda hacer peticiones con solo mencionarlo, aunque el sistema anfitrión es el encargado de hacer cumplir las listas y reglas correspondientes, impidiendo que mensajes o comentarios amplíen por sí solos los permisos del agente.

The first ten lines of a command policy for AI coding agents

En una entrevista, Vinay Thakker, CTO de KloudStax, aborda la gestión de identidades, credenciales y límites de red para agentes de inteligencia artificial. Explica que estos sistemas deben operar con su propia identidad digital cuando realizan tareas para la empresa, o combinar su identidad con la del usuario humano si ejecutan acciones específicas para una sola persona. Asimismo, señala que las credenciales de larga duración deben evitarse y que el uso de servidores proxy ayuda a que los agentes no manejen directamente los secretos, aunque advierte sobre los riesgos de que un proxy actúe de forma confusa o centralice excesivamente la autoridad.

Byoky: Open-source wallet for AI API keys

Byoky se presenta como una herramienta de código abierto destinada a gestionar y almacenar llaves de API de inteligencia artificial. New VOLTA Infostealer Uses Claude, Gemini, and Kimi AI to Rank Victims by Financial Value

Investigadores de ciberseguridad han identificado un nuevo programa malicioso para Windows diseñado para robar información, conocido como VOLTA o VOLTA-AUTODOXER, el cual emplea inteligencia artificial para ordenar los datos sustraídos según su valor económico. Este malware recopila credenciales, cookies, información de pagos, criptomonedas, sesiones de plataformas de mensajería y videojuegos, claves de acceso y capturas de pantalla, además de revisar cuentas de correo electrónico para confirmar direcciones físicas mediante comprobantes de compras recientes. Una vez recopilada toda esta información, el paquete de datos se procesa a través de una pasarela de servicios de modelos de lenguaje grande para su análisis mediante un sistema de instrucciones predeterminado.

Product showcase: Trust Onion uses rotating codewords to verify callers

Trust Onion es una aplicación sin costo diseñada para sistemas operativos macOS, iOS y Android que permite a grupos de confianza verificar la identidad de sus comunicantes mediante tres palabras clave que cambian de manera constante. Además de estas palabras rotativas, la herramienta incorpora funciones como autofotos firmadas, revisiones de mensajes y solicitudes para devolver llamadas. El funcionamiento de esta tecnología busca atender los riesgos asociados con las comunicaciones de voz, especialmente cuando se exige información, acceso o dinero, situaciones que han sido documentadas por Cisco Talos e investigadas en modelos de voz con puertas traseras.

Ransomware gang talked AI agents into doing much of its dirty work

Un grupo de ciberdelincuentes responsable del ransomware Aur0ra, identificado por Sophos como GOLD OGRE, ha utilizado agentes de inteligencia artificial para automatizar gran parte de sus actividades maliciosas dentro de las redes de las víctimas. Estos agentes, que incluyeron herramientas como el asistente de programación Cursor AI y modelos de Anthropic, xAI y Moonshot, se encargaron de mapear redes, buscar credenciales y desplazarse lateralmente con una intervención humana mínima. Para lograr que las herramientas de inteligencia artificial ignoraran sus restricciones de seguridad, los atacantes fingieron que realizaban pruebas diagnósticas o evaluaciones autorizadas de tipo *red team*.

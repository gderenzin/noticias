Inyección SQL en WhatsApp para Dolibarr de Sgestion / EasySoft

Fuente: INCIBE-CERT - Avisos Publicado: 12/11/2026 · 08:34 UTC
Compartir:

In­yec­ción SQL en WhatsApp para Do­li­barr de Sges­tion / Easy­Soft Jue, 12/11/2026 - 09:34 Aviso Re­cur­sos Afec­ta­dos WhatsApp para Do­li­barr, ver­sión 1.9. Des­crip­ción INCIBE ha coor­di­na­do la pu­bli­ca­ción de una vul­ne­ra­bi­li­dad de se­ve­ri­dad alta que afec­ta a WhatsApp for Do­li­barr de Sges­tion / Easy­Soft, un mó­du­lo de ter­ce­ros que in­te­gra la men­sa­je­ría de WhatsApp en Do­li­barr. La vul­ne­ra­bi­li­dad ha sido des­cu­bier­ta por Ga­briel Jesús Ma­cha­do Ta­va­res. A esta vul­ne­ra­bi­li­dad se le ha asig­na­do el si­guien­te có­di­go, pun­tua­ción base CVSS v4.0, vec­tor del CVSS y tipo de vul­ne­ra­bi­li­dad CWE: CVE-2026-76173: CVSS v4.0: 8.8 | CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:N/VA:L/SC:N/SI:N/SA:N | CWE-89 Iden­ti­fi­ca­dor INCIBE-2026-862 So­lu­ción El fa­bri­can­te ha con­fir­ma­do que el par­che que co­rri­ge la vul­ne­ra­bi­li­dad ya ha sido des­ple­ga­do. De­ta­lle CVE-2026-76173 : vul­ne­ra­bi­li­dad de in­yec­ción SQL ciega en el end­point pú­bli­co pu­blic/webhook/re­cei­ver.php del mó­du­lo WhatsApp para Do­li­barr 1.9. El valor del nú­me­ro de te­lé­fono de­ri­va­do del pa­rá­me­tro data.key.re­mo­te­Jid, re­ci­bi­do me­dian­te una pe­ti­ción JSON, se in­cor­po­ra a una con­sul­ta SQL sin es­ca­pe ni pa­ra­me­tri­za­ción. Con la op­ción WHATSAPP_WEBHOOK_ALLOW ha­bi­li­ta­da, un ata­can­te re­mo­to no au­ten­ti­ca­do po­dría ma­ni­pu­lar dicho pa­rá­me­tro para al­te­rar la con­sul­ta. La ex­plo­ta­ción me­dian­te una téc­ni­ca ba­sa­da en tiem­pos po­dría per­mi­tir ob­te­ner in­for­ma­ción de la base de datos y de­gra­dar el ser­vi­cio. 4 - Alta Lis­ta­do de re­fe­ren­cias WhatsApp para Do­li­barr ERP/CRM — Do­lis­to­re CWE-89 — In­yec­ción SQL Eti­que­tas CNA In­yec­ción Soft­wa­re Vul­ne­ra­bi­li­dad CVE Iden­ti­fi­ca­dor CVE Se­ve­ri­dad Ex­plo­ta­ción Fa­bri­can­te CVE-2026-76173 Alta No SGESTION / EASYSOFT…

Firefox Enterprise, de Mozilla, permite a las empresas bloquear la IA oculta en el navegador

Mozilla ha lanzado una plataforma de pago llamada Firefox Enterprise, la cual está diseñada para que las empresas y organizaciones con estrictas normas de seguridad y normatividad puedan regular el acceso de los trabajadores a las aplicaciones web, supervisar la seguridad de los dispositivos y controlar la difusión de información confidencial. Una vulnerabilidad en el sistema «Trusted Publishing» de npm dejó expuestos a más de 1.500 paquetes de npm a posibles ataques de toma de control

Investigadores de seguridad descubrieron una vulnerabilidad en la función de publicación de confianza de npm que permitía a un atacante lanzar nuevas versiones de paquetes ajenos sin necesidad de robar credenciales. Para lograrlo, el atacante solo debía registrar un nombre de repositorio de GitHub que el mantenedor original hubiera abandonado, ya que el sistema registraba los repositorios únicamente por su nombre identificativo y no verificaba identificadores numéricos permanentes. El fallo dejó expuestos más de 1.500 paquetes de npm con millones de descargas acumuladas, abriendo la posibilidad de comprometer equipos mediante scripts maliciosos de postinstalación.

Un atacante remoto y sin autenticación podría aprovechar este fallo enviando peticiones HTTP específicamente diseñadas.

Los registros de un programa de robo de información revelan tokens de IA reutilizables que pueden eludir la autenticación multifactorial (MFA)

Cibercriminales están secuestrando cuentas de usuarios de inteligencia artificial mediante registros de programas maliciosos de robo de información (infostealers) como Lumma Stealer o Vidar. Estos programas recopilan datos variados de sistemas comprometidos, incluyendo credenciales, claves de API y tokens de sesión. Posteriormente, estos elementos son comercializados en foros clandestinos para facilitar ataques posteriores que permiten reutilizar dichos secretos y saltarse la autenticación tradicional basada en credenciales y la autenticación multifactor.

SAP corrige una vulnerabilidad del núcleo según el índice CVSS 10.0 que permite la ejecución remota de código sin autenticación

SAP ha publicado actualizaciones de seguridad para corregir múltiples fallos, destacando una vulnerabilidad de máxima gravedad en el procesamiento de Extended Passport (EPP) del núcleo de SAP. Este problema, identificado como corrupción de memoria y encontrado por la firma de seguridad Onapsis bajo el nombre codificado OVERPASS, permite la ejecución remota de códigos de manera no autenticada, logrando el control total de los datos y procesos comerciales subyacentes con privilegios administrativos. El fallo surge por una falta de validación de límites al deserializar datos EPP, lo cual es explotable mediante solicitudes de red manipuladas que pueden afectar múltiples capas de comunicación y protocolos sin requerir credenciales ni configuraciones erróneas previas.

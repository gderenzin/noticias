Path Traversal en FortiMail de Fortinet

Se ha identificado una vulnerabilidad de tipo path traversal, catalogada con severidad crítica, que afecta a diversas versiones de FortiMail de Fortinet. Esta falla de seguridad, identificada oficialmente, permite que un atacante remoto y sin autenticación logre escribir archivos de forma arbitraria dentro del sistema, abriendo la posibilidad de ejecutar comandos o código que no cuentan con autorización. Tanto el fabricante como CISA han verificado que este fallo está siendo explotado activamente en escenarios reales.

A Shared ChatGPT Link Could Run Attacker Code in Your Session and Read Private Chats

Investigadores de la firma de seguridad Parameter descubrieron una vulnerabilidad en un enlace compartido de ChatGPT que permitía a un atacante ejecutar código dentro de la sesión activa de la víctima y leer sus conversaciones privadas. El problema funcionaba a través de un chat público ordinario que podía distribuirse por correo, mensajes o redes sociales. Para que el ataque funcionara, la víctima simplemente abría el enlace, ya que en una versión posterior el sistema cargaba la vista previa de forma automática sin requerir la instalación de ningún programa ni inicios de sesión adicionales.

Sitios JavaScript comprometidos atacan a los administradores de WordPress para implementar una puerta trasera PHP persistente.

Una campaña reciente pone en peligro a los administradores de WordPress que mantienen su panel de control abierto en el mismo navegador que emplean para navegar por internet. La investigación detalla un cargador de JavaScript que identifica cuando un administrador con sesión activa visita un sitio web afectado, aprovechando la confianza del navegador para introducir una puerta trasera de PHP de forma oculta. Los atacantes evitan la necesidad de conocer la contraseña del administrador gracias al uso de las propias sesiones activas en el navegador.

Reddit to lock content behind logins to fight scrapers

La plataforma de debate Reddit planea transformar su modelo para convertirse progresivamente en un servicio que requiera inicio de sesión, limitando de este modo la visualización de publicaciones para los visitantes que no posean una cuenta de usuario. Esta modificación busca frenar la extracción no autorizada de información y brindar una mayor personalización a los miembros de la comunidad, un aspecto que se ha vuelto insostenible mantener abierto al público general tras dos décadas de funcionamiento. Como parte de este plan, se pondrá en marcha una prueba piloto en regiones seleccionadas fuera de Estados Unidos durante los próximos meses, obligando a los usuarios a iniciar sesión si desean ver el contenido completo.

Northflank security breach leads to abuse of customers' AI API keys

La plataforma de alojamiento en la nube Northflank ha emitido una advertencia a sus usuarios para que cambien todas las credenciales y secretos guardados en su sistema, tras sufrir un fallo de seguridad que resultó en el uso no autorizado de claves de API de inteligencia artificial de los clientes. La empresa reveló este problema después de recibir una alerta de la compañía de seguridad en la nube Wiz, momento en el cual pidió a los usuarios que asumieran que sus variables de entorno habían sido descifradas y robadas. Las variables de entorno se emplean habitualmente para guardar información delicada, como contraseñas, credenciales de servicios en la nube, fichas de autenticación y claves de API.

New Android SMS of Death exploit can remotely crash unpatched phones

Un investigador de seguridad ha dado a conocer un código de prueba para una vulnerabilidad que afecta a Android y que permite interrumpir el servicio móvil o bloquear dispositivos de manera remota mediante el envío de un mensaje de texto modificado. Esta falla de denegación de servicio no requiere que la víctima interactúe con el dispositivo, y el sistema operativo procesa el mensaje antes de que llegue a la bandeja de entrada, por lo que el usuario no ve ninguna señal visual que explique el fallo. El problema se origina debido a una validación incorrecta de un valor de longitud de cabecera en una función específica del sistema.
